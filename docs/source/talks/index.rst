Talks
=====

.. rst-class:: shapiq-examples-lead

Talks on Shapley values and Shapley interactions, given as pages of these docs. Each talk is a
page of slides with notes. Present it, and one slide fills the screen at a time, with the demos of
the docs running live on the slides.
