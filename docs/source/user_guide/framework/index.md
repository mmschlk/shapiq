# The Unified Framework

Explanations from all three lenses fit into one framework
{cite:p}`Fumagalli.2025,Herbinger.2026`. It builds every explanation from three operators, applied
in turn to the model, $\phi = \inter(\behav(\mask \model))$: masking decides how features are
removed, behavior decides what is explained, and interaction decides how the effects of groups of
features enter the explanation. This part introduces each operator.
