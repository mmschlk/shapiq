# Notation

The user guide uses the following symbols. In equations, each of them links to its row here.

| Symbol | Meaning |
| --- | --- |
| <span id="notation-players"></span>$\players$ | the players: the features of the model, or other units such as tokens or data points |
| <span id="notation-nplayers"></span>$\nplayers$ | the number of players |
| <span id="notation-featurespace"></span>$\featurespace$ | the feature space: the inputs of the model |
| <span id="notation-outputspace"></span>$\outputspace$ | the output space: what the model predicts |
| <span id="notation-model"></span>$\model$ | the model to explain |
| <span id="notation-units"></span>$\units$ | the units of an explanation: the sets of features that it explains |
| <span id="notation-explspace"></span>$\explspace$ | the explanation space: what an explanation of a unit is, such as a number or a curve |
| <span id="notation-expl"></span>$\expl$ | a feature-based explanation, which maps each unit to its explanation |
| <span id="notation-mask"></span>$\mask$ | the masking operator: how features are removed |
| <span id="notation-behav"></span>$\behav$ | the behavior operator: what is explained |
| <span id="notation-inter"></span>$\inter$ | the interaction operator: how effects of groups of features enter the explanation |
| <span id="notation-game"></span>$\game$ | the explanation game: a value for every coalition of players |
