# Explainable AI

This part is about feature-based explanations, which explain a trained model after the fact in terms
of its input features. It first defines what such an explanation is, independent of how it is
computed. It then looks at explanations through three lenses, each with its own language: functional
decomposition from statistics, the Taylor expansion from analysis, and cooperative game theory. The
part ends by showing that the three lenses see the same thing: a decomposition of the model into the
effects of groups of features.
